# Backend API Conventions & Design Guidelines

## 1. Route Conventions

- **Base Route Pattern**: `/api/v1/[controller]`
- **Casing**: Lowercase with kebab-case for multi-word resource names (e.g., `/api/v1/shipping-rates`).
- **Resource Naming**: Plural nouns for collections (e.g., `/api/v1/companies`, `/api/v1/branches`).
- **Identifier Pattern**: External public identifiers are GUIDs (`{publicId:guid}`), never internal BIGINT database IDs:
  - `GET /api/v1/companies/{publicId}`
  - `GET /api/v1/branches/{publicId}`

## 3. Query & Pagination Parameters

All list endpoints support standard `PagedRequest` query parameters:

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `page` | `int` | `1` | One-based page index. Must be $\ge 1$. |
| `pageSize` | `int` | `20` | Number of items per page. Maximum allowable: `100`. |
| `sortBy` | `string?` | `null` | Field name to sort by. |
| `sortDescending`| `bool` | `false`| `true` for descending order, `false` for ascending. |

## 4. HTTP Status Codes & Exception Taxonomy

The `GlobalExceptionMiddleware` maps application and domain exceptions into semantic HTTP status codes:

| Exception Type | HTTP Status | Error Code | Description |
| :--- | :--- | :--- | :--- |
| `ValidationException` | `400 Bad Request` | `VALIDATION_FAILED` | Input contract or business validation failure. |
| `DomainException` | `400 Bad Request` | Custom code (`DOMAIN_ERROR`, etc.) | Domain invariant rule violated. |
| `UnauthorizedAccessException` | `401 Unauthorized`| `UNAUTHORIZED` | User is unauthenticated or token is expired. |
| `ForbiddenAccessException` | `403 Forbidden` | `FORBIDDEN` | User does not have branch or role permission. |
| `NotFoundException` / `EntityNotFoundException` | `404 Not Found` | `RESOURCE_NOT_FOUND` | Target entity does not exist. |
| `ConflictException` / `ConcurrencyConflictException` | `409 Conflict` | `RESOURCE_CONFLICT` | Duplicate unique key or concurrent modification. |
| Unhandled exceptions | `500 Internal Server Error` | `INTERNAL_SERVER_ERROR` | Unexpected error. Safe generic message in production. |

### Error Response Format

## 5. Headers & Context Conventions

1. **`X-Correlation-Id`**:
   - Sent by client or auto-generated by `CorrelationIdMiddleware`.
   - Propagated through all downstream logs and returned in response headers.
2. **`X-Branch-Id`**:
   - Transmitted by WinForms client to specify active branch scope for operational transactions.
   - Evaluated by `ICurrentBranchContext` against the user's `UserBranchAccess` permissions.
3. **`Authorization`**:
   - Bearer token standard: `Bearer <jwt_token>`.
